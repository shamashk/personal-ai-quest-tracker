⚙ One-time Google Drive setup
  1. Open the Google Cloud Console and create a project (or pick one).
  2. Go to APIs & Services → Library, search Google Drive API, click Enable.
  3. Go to APIs & Services → OAuth consent screen. Choose External, fill the app name + your email, and under Test users add your own Google address (this lets you use it without Google verification).
  4. Go to APIs & Services → Credentials → Create credentials → OAuth client ID. Application type: Web application.
  5. Under Authorized JavaScript origins add the exact address you'll open this from — e.g. http://localhost:8000, or your hosting URL like https://yourname.github.io. No trailing slash.
  6. Click Create, copy the Client ID, and paste it below.
Privacy: the app requests the drive.appdata scope only — it can read/write one hidden file it creates (ai-quest-save.json) and can't see anything else in your Drive. Your progress is locked behind your own Google sign-in, so even if this HTML file is hosted publicly, no one but you can see your save. This sync only runs when the file is served from a registered origin (localhost or a host) — not inside a preview.

☠ Traps — instant run-enders, avoid at all costs
  • Tutorial Hell: watching courses without shipping. Rule: never finish a learning block without writing or running code.
  • Framework Chasing: the tooling turns over every few months. Anchor on concepts; treat frameworks as disposable gear.

  • Skipping Act III: staying purely technical. The CTO title is an org/business problem — the leadership and commercial quests are not optional side-content.
